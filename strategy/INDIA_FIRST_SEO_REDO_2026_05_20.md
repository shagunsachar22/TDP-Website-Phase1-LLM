## 1. Corrected Decision Rule

Phase 1 is for Indian builders. Therefore:

1. **India volume first:** Is this phrase actually searched in India?
2. **India CPC second:** Is there commercial-intent signal in India?
3. **Brand fit third:** Does the term map to identity work for builders, not generic self-help?
4. **US CPC last:** useful context, but not a decision driver.

The earlier memo over-weighted US CPC examples like `post-exit founder`. That was the wrong lens for this launch. Those terms can stay in a future/global or premium-content parking lot, but they should not drive the Phase 1 site.

## 5. FAQ / Glossary Implications

The FAQ should answer India-search-shaped questions, not only brand-theory questions.

Add or prioritize:

1. “Am I burnt out or just tired from building?”
2. “How is founder burnout different from normal work stress?”
3. “Why do founders seek validation?”
4. “How do I overcome self-doubt as a founder?”
5. “How do I build self-confidence without becoming dependent on outcomes?”
6. “What does career path pressure look like for Indian builders?”
7. “How should a founder run a post-mortem without turning failure into identity?”

These questions let TDP enter through Indian-searchable pain while still answering in the brand’s method:

> pressure -> pause -> physiological space -> clarity -> better action.

## 6. LLM / Agent Implications

The earlier LLM architecture is still valid. What changes is the phrasing agents should see first.

Current agent summary should shift from abstract category language toward India-first pain language:

> The Deliberate Pause helps Indian founders, entrepreneurs, creators, and solopreneurs whose self-worth is tied to output. It addresses founder burnout, imposter syndrome, self-doubt, validation seeking, career-path pressure, and failure through short pauses and mental-training protocols drawn from spiritual practice and proven by elite sport.

This is more likely to match actual user queries than a purely conceptual phrase like “identity work for builders.”
