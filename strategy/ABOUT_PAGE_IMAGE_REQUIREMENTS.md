# About Page Image Requirements

Use these exports for the current About page build. Keep the subject centered with enough negative space for responsive crops.

| Placement | Description | Ratio | Desktop export | Mobile-safe export | Notes |
|---|---|---:|---:|---:|---|
| About hero banner | Cinematic, environmental image of Avi. Not a stage shot. Should feel grounded, warm, and founder-facing. | 16:9 or 3:2 | 2400 x 1350 px or 2400 x 1600 px | 1600 x 1200 px | Face should sit in the upper/middle third. Works under dark mocha/taupe overlay. |
| Identity / early story image | Kathmandu / early hustle / street-level visual, or a textured contextual image if no real photo exists. | 4:3 | 1600 x 1200 px | 1200 x 900 px | Used as a story beat, not a portrait. Keep detail away from edges. |
| Breaking point image | Symbolic body/recovery image: hospital corridor, training mat, quiet recovery, or abstract pressure/body visual. | 4:3 | 1600 x 1200 px | 1200 x 900 px | Should not feel melodramatic. Muted, honest, restrained. |
| Rebuilding image | Contemporary Avi with Yoga Sutras / notes / desk / practice environment. | 4:3 | 1600 x 1200 px | 1200 x 900 px | Should bridge founder life and inner work. |
| Credential portrait | Clear, warm Avi portrait for the card section. | 4:5 portrait | 1600 x 2000 px | 1200 x 1500 px | Face and torso centered. Avoid tight crop around head or hands. |
| Footer / nav logo | TDP logo SVG or transparent PNG. | flexible | SVG preferred | SVG preferred | Use the same logo across nav and footer. |

If only one Avi photo is available for now, prioritize the hero banner and credential portrait first.
