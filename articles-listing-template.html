What changes on the listing page, and the fields behind it

Same logic as the article page: reuse the existing newsletter listing template, change only what SEO needs. The two-column layout, the article cards, the sticky subscribe sidebar, the Load More and the footer CTA are all reused as is.

Why these are the only changes

The existing newsletter listing already had the hard parts: the card layout, the subscribe components, pagination, and the footer. SEO only needs the page to (1) target a keyword with a real H1 and page metadata, (2) expose categories as crawlable cluster pages, and (3) describe itself to crawlers with list schema. Everything else stays, so this is a template tweak, not a rebuild.
